2. Grundsatz: so wenig Daten wie möglich

Diese Webseite besteht aus einfachen, festen Seiten. Sie können sie ansehen, ohne persönliche Daten anzugeben. Konkret bedeutet das:

  • Es werden keine Cookies gesetzt.
  • Es findet keine Webanalyse statt – kein Google Analytics, kein Matomo, keine Zählpixel.
  • Es werden keine Schriften von fremden Servern geladen; die Seite nutzt ausschließlich die auf Ihrem Gerät vorhandenen Systemschriften.
  • Es ist keine Karte eingebettet. Auf der Seite „Anfahrt“ finden Sie lediglich einen Link, der Google Maps erst öffnet, wenn Sie ihn selbst anklicken.
  • Es gibt kein Kontaktformular, keine Kommentarfunktion und keine Anmeldung.
  • Es sind keine Social-Media-Schaltflächen eingebunden.

Aus diesem Grund ist auf dieser Webseite auch kein Einwilligungsbanner erforderlich.
